# TypeScript Hello World

一个用 TypeScript 和 Vite 实现的简单前端 Hello World 页面。

## 开始使用

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可访问页面。

## 构建

```bash
npm run build
npm run preview
```

构建结果输出到 `dist/`。

## 目录结构

```
.
├── index.html        # 页面入口
├── public/           # 静态资源
│   └── favicon.svg
├── src/
│   ├── main.ts       # TypeScript 入口与交互逻辑
│   └── style.css     # 页面样式
├── package.json
└── tsconfig.json
```
